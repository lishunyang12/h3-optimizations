Run on the 5000 and target SKU

Follow the complete setup guide to prepare pinned dependencies, model weights and AdaLN caches, then edit the machine-specific asset paths. Use the same source revision, GPU count, inputs and cache files on both machines.

git clone https://github.com/lishunyang12/h3-optimizations.git
cd h3-optimizations
git checkout __COMMIT__
python3 scripts/sku_benchmark.py prepare --variant avatar5 --output /opt/h3-runtime-avatar5
python3 scripts/sku_benchmark.py prepare --variant reference --output /opt/h3-runtime-15s
cp configs/sku-assets.example.json /tmp/h3-assets.json
# After editing paths, downloading pinned weights and building caches:
python3 scripts/sku_benchmark.py suite --cases main \
  --assets /tmp/h3-assets.json --gpus 0,1,2,3,4,5,6,7 \
  --output /results/pro5000
# On the target machine, use /results/target-sku as the output directory.
python3 scripts/sku_benchmark.py compare \
  /results/pro5000/5s-avatar-ref2va-4step/result.json \
  /results/target-sku/5s-avatar-ref2va-4step/result.json \
  --output /results/avatar-comparison.json

Repeat the comparison for 15s-4step-mxfp8-sage-nvfp4. The main suite runs exactly these two cases. The launcher exits with a reason if GPU architecture, count, memory or availability does not meet the selected case requirements.

What makes the comparison reproducible

Pinned and recorded

  • Original prompts, reference images, seeds, frame counts, steps and precision settings.
  • Model and cache byte hashes, actual source and binary fingerprints, and dependency versions.
  • Driver-reported GPU name, PCI IDs, memory samples, driver, clocks, power limit, CPU and GPU interconnect topology.
  • Separate warmup records; timing from local request launch to the complete MP4 written to disk.

Checks and interpretation

  • Four-step cases audit actual DiT calls, quantization fallbacks, VAE execution and RDMA evidence.
  • Frame counts and full audiovisual decoding are checked outside the timed interval. MP4s and logs are retained.
  • Different configurations, weights, sources, dependencies or foreign GPU activity invalidate a comparison.
  • CPU, interconnects, power and clocks still affect end-to-end latency. This is a same-workload system comparison.

The avatar replay excludes chat, RTMP and live playback delay. Quantized configurations are lossy. Cross-GPU output-byte differences are reported separately and do not automatically rank perceptual quality. Original benchmark prompts remain verbatim to preserve the workload.
